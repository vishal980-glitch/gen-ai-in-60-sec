# Gen AI in 60 Sec (Hinglish)

45 one-minute lessons on Generative AI with simple Python code. Watch the Short, then run the code yourself.

## How to run (no setup)
1. Tap **Open in Colab** next to a day (works on phone and PC, free, Google login only).
2. Press the play button on the code cell.
3. Do the day's challenge and comment your output under the video.
